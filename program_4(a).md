
# Program 4(a): Object Detection Using EfficientDet-D0

**Aim:** To detect objects in an uploaded image using a pretrained EfficientDet-D0 model and display their labels, confidence scores, and bounding boxes.

**Dataset Used:** User-uploaded traffic image (`traffic.jpg`). No separate dataset is used.

**Results:** The program detects objects such as cars and other vehicles in the traffic image and draws green bounding boxes around detected objects with confidence scores above 0.5. The annotated image is displayed in Google Colab.
